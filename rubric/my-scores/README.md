# rubric/my-scores/

Your scorecards. Gitignored — everything in here except this file stays local.

The rest of the repo is a curriculum anyone can clone and run. Scores are the one thing that
isn't reusable: they're a claim about one person's competence on one date, and they'd be noise
in someone else's clone.

Naming: `YYYY-MM-DD-scorecard.md`, from [`../SCORECARD-TEMPLATE.md`](../SCORECARD-TEMPLATE.md).
Cadence and the evidence rule are in [`../README.md`](../README.md).

**These are not backed up by pushing.** That's the tradeoff for keeping them private — if the
disk dies, 24 weeks of self-assessment history dies with it. Either accept that or point this
directory at a private repo or synced location of your own.

If you're forking this repo to learn from: nothing here is prescriptive. Delete this note and
start scoring.
